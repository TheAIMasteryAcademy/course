# Exam maps

Which parts of the course help with which Microsoft certification. Status checked in November 2026. Microsoft updates exams often, so always read the official study guide on Microsoft Learn before you book.

| Certification | Exam | Status | Where the course covers it |
|---|---|---|---|
| Azure AI Fundamentals | AI-901 | Live. Replaced AI-900, which retired on 30 June 2026 | Seasons 0, 3, 4, 5 and 6, plus the first look lab and lab track A |
| Azure Data Fundamentals | DP-900 | Live | Seasons 0, 1 and 2 |
| Fabric Data Engineer Associate | DP-700 | Live | Season 2 and lab track B |
| Azure AI Apps and Agents Developer Associate | AI-103 | Live. Replaced AI-102 | Seasons 5 and 6, and lab track C |
| Machine learning and generative AI operations (MLOps) | AI-300 | Live. Microsoft points former DP-100 candidates here | Season 7 and lab track D |

## Notes

- **AI-901 is not theory only.** It includes hands-on work with Microsoft Foundry and basic Python. That is why the course adds a short first look lab after Season 2, so you can try the exam before the full hands-on track.
- **DP-100 (Azure Data Scientist Associate) retired on 1 June 2026.** Older study guides still mention it.
- In the videos we use the certification names, not the exam codes, because codes change. The codes live here, and this page is kept up to date.
