# Lesson 0.3: quiz before the lesson

**1. In machine learning, the answer we want the model to predict is called:**
A) A feature  B) A label  C) A cell  D) A column name

**2. Why do we keep some data hidden from the model during training?**
A) To save memory  B) To test it on examples it has never seen  C) To make training faster

**3. Predicting the price of a house is:**
A) Classification  B) Regression  C) Clustering

<details>
<summary>Show answers</summary>

1. B. The label is the answer. Features are the inputs we use to predict it.
2. B. Scoring on unseen examples tells us how the model will do on new data.
3. B. Predicting a number is regression.
