# Lesson 0.2: quiz after the lesson

**1. The penguins table has 344 rows and 7 columns. What is its shape?**
A) 7 by 344  B) 344 by 7  C) 2,408  D) 351

**2. T-shirt sizes small, medium and large are:**
A) Numerical, continuous  B) Numerical, discrete  C) Categorical, nominal  D) Categorical, ordinal

**3. A JSON log from an app is an example of:**
A) Structured data  B) Semi-structured data  C) Unstructured data  D) Not data

<details>
<summary>Show answers</summary>

1. B. Shape is always rows first, then columns: 344 by 7.
2. D. They are labels with a natural order, so they are ordinal.
3. B. JSON has labels (keys) but no fixed table, so it is semi-structured.
