# Lesson 0.2: homework

Three levels. Stop at any of them.

## Core

Take the [after-lesson quiz](quiz-post.md).

## Stretch (no code)

1. Download [penguins.csv](../../../data/penguins/penguins.csv) and open it in Excel, Google Sheets or LibreOffice Calc.
2. For each of the 7 columns, write down whether it is numerical or categorical.
3. Find one missing value. In this file a missing value is an empty cell.

Bonus: filter the `species` column and check that you get 152 Adelie, 124 Gentoo and 68 Chinstrap.

## Challenge

Find a public dataset you care about, for example from your city, your country's open data portal or your industry. Answer the five dataset questions for it and post them in [Discussions](https://github.com/TheAIMasteryAcademy/course/discussions).

Coder? Open [explore-penguins.ipynb](explore-penguins.ipynb) in GitHub Codespaces and run it. It answers the five questions for the penguins in a few lines of Python.
