# Contributing

Thank you for helping make this course better. The most useful help is simple: tell us when something is wrong or unclear.

## Report a mistake

Open an issue with the **Content error** form: https://github.com/TheAIMasteryAcademy/course/issues/new/choose

Say which lesson, what is wrong, and what you think it should say. A link to a source helps a lot.

## Ask a question or post homework

Use [Discussions](https://github.com/TheAIMasteryAcademy/course/discussions), not issues. Questions help everyone when they are in one place.

## Pull requests

Small fixes are welcome: typos, broken links, a clearer sentence, a better quiz option.

1. Fork the repository and make your change on a new branch.
2. Keep one fix per pull request.
3. Explain the change in the pull request description.

Please don't add:

- Diagrams or text copied from other courses, books, newsletters or websites. Everything here is original or properly licensed.
- Logos or product icons of Microsoft or any other company.
- Keys, passwords, subscription IDs, tenant IDs or personal data.

## Translations

Translations are welcome later in a `translations/` folder. Open an issue first so we can agree on the structure.
