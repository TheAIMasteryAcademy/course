# Episode 1 quiz

Answer all five, then check below.

**1. Which is the broadest idea?**
A) Machine learning  B) Deep learning  C) Artificial intelligence  D) Generative AI

**2. Predicting an apartment's price from its size and number of rooms is called:**
A) Clustering  B) Regression  C) Classification  D) Big data

**3. The three Vs of big data are:**
A) Volume, velocity, variety  B) Value, vision, version  C) Volume, value, visuals  D) Velocity, vectors, views

**4. Which statement about data science is true?**
A) It always needs AI  B) It only works on big data  C) A lot of it is careful counting and good charts  D) It is a type of deep learning

**5. In this course, which Azure tool do we use to build generative AI apps and agents?**
A) Azure Databricks  B) Microsoft Fabric  C) Microsoft Foundry  D) Azure portal

<details>
<summary>Show answers</summary>

1. C. AI is the big circle. Machine learning, deep learning and generative AI all sit inside it.
2. B. Predicting a number is regression. Predicting a category is classification.
3. A. Volume is how much, velocity is how fast, variety is how many shapes.
4. C. Plenty of data science answers questions without any AI.
5. C. Microsoft Foundry is where you pick a model, test it and build agents on top of it.
