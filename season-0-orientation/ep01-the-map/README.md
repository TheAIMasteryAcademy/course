## What you learned

- **Data science** answers questions with data. A lot of it needs no AI at all: careful counting and good charts.
- **Big data** is data too big, too fast or too messy for one machine. The three Vs are volume, velocity and variety. Engines like Apache Spark split the work across a cluster, and the data usually lands in a data lake first.
- **Artificial intelligence** is the broad goal: computers doing things that normally need human intelligence.
- **Machine learning** learns patterns from examples instead of hand-written rules. Regression predicts a number, classification predicts a category, clustering groups things without labels.
- **Deep learning** uses neural networks with many layers. **Generative AI** creates new text, images, code or audio. **AI agents** use a language model to plan, call tools and take actions.
- **Azure tools in this course:** Azure Machine Learning, Microsoft Fabric, Azure Databricks, Microsoft Foundry and the Azure portal.
