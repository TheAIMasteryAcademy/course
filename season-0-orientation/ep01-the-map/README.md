## What you learned
- Data science answers questions with data. Much of it needs no AI.
- Big data is data too big, too fast or too messy for one machine (volume, velocity, variety). Spark splits the work.
- AI is the broad goal. Machine learning learns patterns from examples. Deep learning uses neural networks. Generative AI creates new content, and agents use language models to plan and act.
- Azure tools in this course: Azure Machine Learning, Microsoft Fabric, Azure Databricks, Microsoft Foundry, and the Azure portal.
